Edge-to-Cloud Wildfire Detection System

This project demonstrates a full-stack AI solution for detecting wildfires using satellite imagery, optimized for edge-to-cloud inference. Built around U-Net for segmentation, it leverages PyTorch and ONNX Runtime to support real-time processing on edge devices. With additional integrations for TensorRT and profiling, the system balances speed, memory, and model accuracy — simulating a realistic deployment environment for environmental monitoring or emergency response teams.

Key Features
  • > Dataset Integration: Uses open-source Sentinel-2 satellite imagery from the CEMS Wildfire Dataset
  • > Semantic Segmentation: U-Net architecture trained to detect wildfire-affected regions at pixel level
  • > Preprocessing Pipeline: Converts raw GeoTIFF data into normalized, resized NumPy arrays with masks
  • > Distributed Training: Supports PyTorch-based multi-GPU training using DistributedDataParallel (DDP)
  • > ONNX Model Export: Converts PyTorch model to ONNX for inference acceleration
  • > Stream Simulator: Simulates image streaming from edge devices with real-time frame-by-frame inference
  • > Performance Profiling: Logs inference latency and memory usage per frame with summary metrics
Tools & Technologies
  • > PyTorch + DDP
  • > ONNX Runtime + TensorRT
  • > Streamlit
  • > NumPy, GeoTIFF
Workflow
  • > Preprocess Sentinel-2 imagery
  • > Train U-Net and export to ONNX
  • > Run streaming inference with performance profiling
Output / Result

Achieved 5.10 ms/frame with TensorRT FP16 at 128×128 resolution; logged latency + memory usage per frame.
